### 2. ✅ Автосохранение черновиков

**Функциональность:**
- Автоматическое сохранение каждые 30 секунд
- Работает только для существующих материалов
- Сохраняет только черновики (status = 'draft')
- Не сохраняет при ошибках валидации

**Индикация:**
- "Автосохранение..." - в процессе
- "Автосохранено: [время]" - время последнего сохранения

---

### 3. ✅ Валидация slug

**Функциональность:**
- Проверка уникальности slug в реальном времени
- Проверка формата (латиница, цифры, дефисы)
- Минимальная длина: 3 символа
- Задержка проверки: 500мс (debounce)

**Визуальная индикация:**
- Красная рамка при ошибке
- Сообщение об ошибке под полем
- Кнопка "Сохранить" отключена при ошибке
