# Визуальное представление формы Telegram-бота

**Дата:** 2024-12-19  
**Версия:** 1.0

---

## 🎨 Визуальные примеры сообщений

### Шаг 1: Приветствие

```
╔════════════════════════════════════╗
║  Добро пожаловать в систему        ║
║  обращений ОСС ДВФУ!               ║
╚════════════════════════════════════╝

Для подачи обращения заполните форму.
Все данные будут сохранены конфиденциально.

Вы можете подать обращение:
• 🔒 Анонимно (без указания контакта)
• 📞 С указанием контакта (для уточнения)

────────────────────────────────────
[✅ Начать]  [ℹ️ Помощь]  [📊 Статистика]
```

---

### Шаг 2: Выбор анонимности

```
╔════════════════════════════════════╗
║  Выберите способ подачи обращения  ║
╚════════════════════════════════════╝

🔒 Анонимно
Ваше обращение будет обработано, но мы
не сможем связаться с вами для уточнения
деталей.

📞 С контактом
Укажите email или Telegram для связи.
Это поможет нам быстрее решить вопрос.

────────────────────────────────────
[🔒 Подать анонимно]
[📞 Указать контакт]
[◀️ Назад]
```

---

╚════════════════════════════════════╝

```

```

### Шаг 4: Выбор направления

```
╔════════════════════════════════════╗
║  Выберите направление обращения    ║
║  (необязательно)                    ║
╚════════════════════════════════════╝

Это поможет быстрее направить ваше

Если не уверены, можете пропустить.

────────────────────────────────────

[🏗️ Инфраструктура]
[💰 Стипендиальный]
[🌍 Международный]

[❌ Пропустить]
[◀️ Назад]
```

---

### Шаг 5: Ввод темы

```
╔════════════════════════════════════╗
║  📝 Введите тему обращения         ║
╚════════════════════════════════════╝

Кратко опишите суть вашего вопроса
(минимум 5 символов).

Примеры:
• Проблема с доступом к Wi-Fi
• Вопрос о стипендиях
• Недостаток мест в библиотеке

────────────────────────────────────
[◀️ Назад]
```

**Пример ввода:**
```
Проблема с доступом к Wi-Fi в библиотеке
```

---

### Шаг 6: Ввод описания

```
╔════════════════════════════════════╗
║  📄 Опишите ситуацию подробно      ║
╚════════════════════════════════════╝

Расскажите детали вашего обращения.
Чем подробнее описание, тем быстрее
мы сможем помочь (минимум 20 символов).

────────────────────────────────────
[◀️ Назад]
```

**Пример ввода:**
```
Не могу подключиться к Wi-Fi в библиотеке
уже неделю. На других устройствах все
работает, но на моем ноутбуке постоянно
ошибка подключения. Пробовал обновить
драйверы, не помогло.
```

---

### Шаг 7: Ввод контакта (не анонимно)

```
╔════════════════════════════════════╗
║  📞 Укажите контакт для связи      ║
╚════════════════════════════════════╝

Введите email или Telegram (@username)
для связи.

Формат:
• Email: example@mail.ru
• Telegram: @username

Мы используем контакт только для
уточнения деталей обращения.

────────────────────────────────────
[◀️ Назад]  [❌ Отменить]
```

**Пример ввода:**
```
@username
```
или
```
student@mail.ru
```

**При ошибке:**
```
❌ Укажите email (example@mail.ru)
   или Telegram (@username)
```

## 🎯 Особенности дизайна

### Эмодзи для категорий

- 🏫 Школа/Институт
- 📌 Направление
- 📝 Тема
- 📄 Описание
- 📞 Контакт
- 📎 Вложения
- 🔒 Анонимно
- ✅ Подтверждение
- ❌ Отмена
- ⚠️ Предупреждение
- 🔍 Проверка

### Форматирование текста

- **Жирный текст** для заголовков
- *Курсив* для примеров
- `Моноширинный` для кодов
- Эмодзи для визуальной навигации
- Разделители `────────────────────`

### Inline Keyboard

- Максимум 2-3 кнопки в ряд
- Компактные кнопки для списков (школы)
- Кнопки с эмодзи для действий
- Кнопка "Назад" на каждом шаге

---

## 📱 Адаптация для мобильных

### Компактность

- Короткие сообщения (до 5-6 строк)
- Минимум текста на кнопках
- Группировка информации

### Навигация

- Всегда доступна кнопка "Назад"
- Четкое указание текущего шага
- Визуальная индикация прогресса (опционально)
