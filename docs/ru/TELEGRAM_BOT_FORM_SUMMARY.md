## 🎯 Ключевые особенности

### ✅ Обязательные поля
- Тема обращения (минимум 5 символов)
- Описание (минимум 20 символов)
- Школа/Институт (выбор из 12 школ)

### ⭕ Опциональные поля
- Направление (4 направления)
- Контакт (email или Telegram)
- Вложения (до 5 файлов, 20 MB каждый)

### 🔒 Анонимная подача
- ✅ Полностью анонимная подача (без контакта)
- ✅ Контакт запрашивается только при неанонимной подаче
- ✅ Используется Telegram User ID только для связи обращений (не сохраняется)

## 📊 Структура формы

### 10 шагов заполнения:

1. **Начало** - Приветствие и выбор действий
2. **Выбор анонимности** - Анонимно или с контактом
3. **Выбор школы** - 12 школ ДВФУ (inline keyboard, по 2 в ряд)
4. **Выбор направления** - 4 направления (опционально)
5. **Ввод темы** - Текст (минимум 5 символов)
6. **Ввод описания** - Текст (минимум 20 символов)
7. **Ввод контакта** - Email или Telegram (только если не анонимно)
8. **Вложения** - До 5 файлов, 20 MB каждый (опционально)
9. **Предпросмотр** - Проверка всех данных перед отправкой
10. **Подтверждение** - Успешная отправка с кодом обращения

## 📤 Формат данных для API

### JSON структура

```json
{
  "title": "Проблема с доступом к Wi-Fi",
  "description": "Не могу подключиться к Wi-Fi...",
  "institute": "ИМО",
  "direction_id": "uuid-направления" | null,
  "is_anonymous": true | false,
  "contact_type": "telegram" | "email" | null,
  "contact_value": "@username" | "email@example.com" | null,
  "files": [
    {
      "file_id": "telegram-file-id",
      "file_name": "document.pdf",
      "mime_type": "application/pdf"
    }
  ]
}
```

### API Endpoint

```
POST /api/appeals
Content-Type: application/json
Authorization: Bearer {BOT_API_KEY}
```

### Ответ API

```json
{
  "success": true,
  "public_token": "ABC123XYZ",
  "appeal_id": "uuid"
}
```

## 🔐 Анонимная подача

### Особенности

1. **Без контакта:**
   - `is_anonymous = true`
   - `contact_type = null`
   - `contact_value = null`

2. **Связь с пользователем:**
   - Telegram User ID используется только для связи обращений одного пользователя
   - User ID НЕ сохраняется в обращении
   - Пользователь получает `public_token` для проверки статуса

3. **Ограничения:**
   - Невозможно связаться с пользователем для уточнения деталей
   - Ответ придет через бота, если пользователь проверит статус по токену

## 💻 Технические детали

### Используемые технологии

- **Telegram Bot API** - для работы с ботом
- **python-telegram-bot** - для Python (рекомендуется)
- **Inline Keyboard** - для выбора школ и направлений
- **Conversation Handler** - для управления состоянием формы

### State Machine

```
START
  ↓
SELECT_ANONYMITY
  ↓
SELECT_SCHOOL
  ↓
SELECT_DIRECTION (опционально)
  ↓
ENTER_TITLE
  ↓
ENTER_DESCRIPTION
  ↓
[Если не анонимно] → ENTER_CONTACT
[Если анонимно]    → ADD_ATTACHMENTS
  ↓
ADD_ATTACHMENTS (опционально)
  ↓
PREVIEW
  ↓
CONFIRM
  ↓
SUBMIT → API
  ↓
SUCCESS
```
