# Система личных кабинетов

**Дата создания:** 2024-12-19  
**Статус:** ✅ Реализовано

---

## 📋 Обзор

Создана единая система личных кабинетов с четким разделением по ролям пользователей. Все кабинеты доступны через единую точку входа `/cabinet/login`.

---

## 🎯 Структура кабинетов

### Роли пользователей

1. **member** (Член ОСС)
   - Доступ к статистике
   - Просмотр обращений своего направления
   - Личный профиль

2. **lead** (Руководитель направления)
   - Все права member +
   - Управление контентом
   - Управление обращениями своего направления
   - Дашборды по направлению

3. **board** (Руководство ОСС)
   - Полный доступ ко всем функциям
   - Управление всеми обращениями
   - Управление всем контентом
   - Управление пользователями
   - Системные настройки

4. **staff** (Аппарат)
   - Просмотр всех обращений
   - Просмотр дашбордов
   - Технические настройки
   - Нет прав на изменение данных

## 🔐 Система защиты

### CabinetGuard

Компонент `CabinetGuard` защищает маршруты и проверяет права доступа:

```tsx
<CabinetGuard requiredRole="board">
  {/* Контент только для board */}
</CabinetGuard>

<CabinetGuard requiredRole={['lead', 'board']}>
  {/* Контент для lead и board */}
</CabinetGuard>
```

### Автоматический редирект

- При входе пользователь автоматически перенаправляется на свой кабинет
- При попытке доступа к недоступному разделу - редирект на главную страницу кабинета
- При отсутствии авторизации - редирект на `/cabinet/login`

## 🚀 Использование

### Вход в кабинет

1. Перейти на `/cabinet/login`
2. Ввести email и пароль
3. Автоматический редирект на кабинет по роли:
   - `member` → `/cabinet/member`
   - `lead` → `/cabinet/lead`
   - `board` → `/cabinet/board`
   - `staff` → `/cabinet/staff`

### Навигация

Все страницы кабинета имеют единую навигацию (`CabinetNav`), которая показывает:
- Доступные разделы для текущей роли
- Email пользователя
- Роли пользователя
- Кнопку выхода

## 🔧 Утилиты

### `lib/cabinet.ts`

Основные функции:

- `getUserCabinetInfo()` - Получить информацию о кабинете пользователя
- `determineCabinetType()` - Определить тип кабинета по ролям
- `getCabinetUrl()` - Получить URL кабинета для редиректа
- `hasCabinetAccess()` - Проверить доступ к разделу
- `getAvailableSections()` - Получить список доступных разделов

Старые кабинеты (`/manage`, `/admin`) остаются для обратной совместимости, но рекомендуется использовать новую систему `/cabinet`.

### План миграции:

1. ✅ Создана новая система `/cabinet`
2. ⏳ Обновить ссылки на главной странице
3. ⏳ Добавить редиректы со старых кабинетов
4. ⏳ Обновить документацию

## 📝 Примеры использования

### Создание защищенной страницы

```tsx
'use client';

import CabinetGuard from '../../../components/CabinetGuard';

export default function MyPage() {
  return (
    <CabinetGuard requiredRole={['lead', 'board']}>
      <main className="min-h-screen bg-oss-dark">
        <div className="max-w-7xl mx-auto px-4 py-12">
          <h1>Моя страница</h1>
          {/* Контент страницы */}
        </div>
      </main>
    </CabinetGuard>
  );
}
```

### Проверка доступа в компоненте

```tsx
import { getUserCabinetInfo, hasCabinetAccess } from '../lib/cabinet';

async function MyComponent() {
  const info = await getUserCabinetInfo();
  
  if (info && hasCabinetAccess(info.cabinetType, 'board')) {
    // Показать контент для board
  }
}
```
