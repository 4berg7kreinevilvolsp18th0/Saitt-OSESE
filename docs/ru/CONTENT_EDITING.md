## 📝 Создание и редактирование

### Доступ:

**URL:** `/admin/content/edit/new` (создание)  
**URL:** `/admin/content/edit/{id}` (редактирование)

### Поля формы:

- **Тип материала:** `news` (Новость), `guide` (Гайд), `faq` (FAQ)
- **Статус:** `draft` (Черновик), `published` (Опубликовано), `archived` (Архив)
- **Направление:** Опционально, выбор из списка направлений
- **Заголовок:** Обязательное поле
- **Slug (URL):** Автоматически генерируется из заголовка, можно изменить вручную
- **Содержание:** Markdown формат

---

## 💾 Автосохранение

### Как работает:

- Автоматически сохраняет черновики каждые **30 секунд**
- Работает только для существующих материалов (не для новых)
- Сохраняет только если статус = `draft`
- Не сохраняет если есть ошибка в slug

### Индикация:

- "Автосохранение..." - в процессе сохранения
- "Автосохранено: [время]" - время последнего сохранения

---

## ✅ Валидация

### Slug валидация:

- Проверка уникальности slug
- Проверка формата (только латиница, цифры, дефисы)
- Минимальная длина: 3 символа
- Автоматическая проверка при вводе (с задержкой 500мс)

### Ошибки:

- "Этот slug уже используется" - если slug занят другим материалом
- "Ошибка при проверке slug" - техническая ошибка

### Визуальная индикация:

- Красная рамка при ошибке
- Красный текст ошибки под полем
- Кнопка "Сохранить" отключена при ошибке

---

## 👁️ Предпросмотр

### Режимы:

1. **Редактирование** - только текстовое поле
2. **Предпросмотр** - только предпросмотр Markdown
3. **Раздельно** - редактор и предпросмотр рядом (split view)

### Переключение:

Кнопки в верхней части поля содержания:
- "Редактировать" - режим редактирования
- "Предпросмотр" - режим предпросмотра
- "Раздельно" - split view

### Поддержка Markdown:

- Заголовки (# ## ###)
- Жирный текст (**текст**)
- Курсив (*текст*)
- Списки (- пункт)
- Ссылки ([текст](url))
- Код (inline и блоки)
- Цитаты (> текст)

---

## 🗑️ Удаление

### Удаление одного материала:

1. Открыть материал для редактирования
2. Нажать кнопку "Удалить"
3. Подтвердить удаление
4. Материал будет удалён безвозвратно

### Массовое удаление:

1. Выбрать материалы на странице списка (чекбоксы)
2. Нажать "Удалить" в панели массовых операций
3. Подтвердить удаление

**⚠️ Внимание:** Удаление необратимо!

## 📋 Список материалов

### Функции:

- **Поиск** - по заголовку, slug, направлению
- **Фильтры** - по статусу и типу
- **Массовые операции:**
  - Опубликовать
  - В черновики
  - В архив
  - Удалить

### Действия для каждого материала:

- **Редактировать** - открыть редактор
- **Просмотр** - открыть на сайте (в новой вкладке)
- **Опубликовать/Снять с публикации** - быстрая смена статуса

## 🔧 Backend API

### Endpoints:

```python
# Получить контент
GET /api/content/{content_id}

# Создать контент
POST /api/content
Body: ContentCreate

# Обновить контент
PATCH /api/content/{content_id}
Body: ContentUpdate

# Удалить контент
DELETE /api/content/{content_id}
```

### CRUD функции:

```python
# crud.py
create_content(db, content: ContentCreate) -> Content
update_content(db, content_id: UUID, content_update: ContentUpdate) -> Optional[Content]
delete_content(db, content_id: UUID) -> bool
get_content(db, content_id: UUID) -> Optional[Content]
get_content_by_slug(db, slug: str) -> Optional[Content]
```

## 📚 Примеры

### Создание новости:

1. Перейти на `/admin/content/edit/new`
2. Выбрать тип: "Новость"
3. Ввести заголовок (slug сгенерируется автоматически)
4. Написать содержание в Markdown
5. Выбрать статус: "Опубликовано"
6. Нажать "Опубликовать"

### Редактирование:

1. Открыть материал из списка
2. Внести изменения
3. Изменения автоматически сохраняются (если черновик)
4. Нажать "Сохранить" для финального сохранения

### Массовая публикация:

1. Выбрать несколько черновиков (чекбоксы)
2. Нажать "Опубликовать" в панели массовых операций
3. Все выбранные материалы будут опубликованы
